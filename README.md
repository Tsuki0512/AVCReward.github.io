# AVCReward project page

This repository contains the static GitHub Pages site for AVCReward.

## Local preview

Because the site is plain HTML, CSS, and JavaScript, it needs no build step. From the repository root, run one of the following commands:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

1. Push the repository to `Tsuki0512/AVCReward.github.io`.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.

This repository is a project site, so GitHub will show its exact public URL in the Pages settings. With the current owner and repository name, it is typically `https://tsuki0512.github.io/AVCReward.github.io/`.

## Before submission

Update the placeholder authors, affiliations, abstract, method text, metrics, chart, and BibTeX entry in `index.html`. Replace the sample buttons with the final paper and code URLs when they are available.
