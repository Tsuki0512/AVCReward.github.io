# AVC-Reward project page

Static project page for **AVC-Reward: Event-Centric Audio-Video Consistency Evaluation**.

## Preview locally

The site uses plain HTML, CSS, and JavaScript. From the repository root, run:

    python -m http.server 8000

Then open <http://localhost:8000>.

## Publish with GitHub Pages

In the repository’s **Settings → Pages**, select **Deploy from a branch**, then choose the main branch and root folder.

Paper figures and the playable case-study videos are loaded from the local ref directory. Keep that directory alongside index.html when publishing.
